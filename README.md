# Тренажер завдань

Простий сайт без бібліотек: `index.html`, `style.css`, `script.js`.
Завдання лежать у теці `exercises/` у вигляді `.json` файлів. Питання показуються по одному: наступне з'являється лише після відповіді на попереднє.

```
quiz-site/
├── index.html
├── style.css
├── script.js
├── README.md
└── exercises/
    ├── index.json                      ← список файлів із завданнями
    ├── dieprykmetnykovyi-zvorot.json
    └── example-matching.json
```

## Як запустити

Браузер не дозволяє сайту читати файли, якщо відкрити `index.html` подвійним кліком. Потрібен простий сервер.

**На комп'ютері** (потрібен Python): відкрий термінал у теці `quiz-site` і виконай

```
python -m http.server 8000
```

Потім відкрий `http://localhost:8000`.

**На телефоні в тій самій Wi-Fi мережі:** дізнайся IP комп'ютера (у Windows команда `ipconfig`) і відкрий на телефоні `http://ІР-комп'ютера:8000`.

**Щоб працювало скрізь без твого комп'ютера:** завантаж теку на безкоштовний хостинг (GitHub Pages, Netlify, Cloudflare Pages). Сестрі достатньо буде посилання.

## Як додати нове завдання

1. Створи файл у `exercises/`, наприклад `pryslivnyk.json`.
2. Допиши його назву в `exercises/index.json`:

```json
[
  "dieprykmetnykovyi-zvorot.json",
  "example-matching.json",
  "pryslivnyk.json"
]
```

Сайт сам не бачить вміст теки, тому нові файли треба вписувати в `index.json`. Якщо у файлі є помилка, на сторінці з'явиться червона картка з описом, що саме виправити.

## Формат `.json` файлу

```json
{
  "title": "Назва набору завдань",
  "questions": [ ...питання... ]
}
```

| Поле | Обов'язкове | Опис |
|---|---|---|
| `title` | ні | Назва, яка показується в списку. Без неї буде назва файлу. |
| `questions` | так | Список питань. Їх може бути скільки завгодно. |

Питань може бути безліч, вони показуються в тому порядку, у якому записані.

### Правила для всіх типів

- Літери варіантів: `А Б В Г Д Е`. Тільки українські літери. Не латинські `A B C`: латинська `A` і українська `А` виглядають однаково, але це різні символи.
- У тексті варіантів **не пиши** «А)», «Б.» чи номери. Сайт сам додає літери за порядком у списку `options`.
- Варіантів у `options` від 2 до 6 (А–Е).
- `explanation` (необов'язково) показується після відповіді. Один–два речення, чому відповідь саме така.
- Текст у JSON пиши в подвійних лапках. Лапки всередині тексту екрануй так: `\"` або використовуй «ялинки».

### Тип 1: `single` (звичайне питання, одна правильна відповідь)

Це «1 — А, 2 — Б». Тип можна не вказувати, `single` діє за замовчуванням.

```json
{
  "type": "single",
  "question": "Дієприкметниковий зворот ужито в реченні",
  "options": [
    "Був яскравий сонячний день, кінець квітня.",
    "Кінь став дибки, хропучи й гризучи вудечку.",
    "Листя, зірване вітром, кружляло над нами.",
    "Надворі гула мокра березнева завірюха."
  ],
  "correct": "В",
  "explanation": "«Зірване вітром» — дієприкметниковий зворот."
}
```

| Поле | Опис |
|---|---|
| `type` | `"single"` |
| `question` | Текст питання |
| `options` | Список варіантів без літер. Перший = А, другий = Б і так далі |
| `correct` | Одна літера правильного варіанта, наприклад `"В"` |
| `explanation` | Необов'язково |

### Тип 2: `matching` (відповідність: пункти 1–4 до варіантів А–Д)

Кожному пункту зі списку `items` потрібно підібрати літеру з `options`. Варіантів у `options` може бути **більше**, ніж пунктів. Тоді зайвий варіант не підходить до жодного пункту (так буває в завданнях НМТ). Один варіант може підходити й до кількох пунктів.

```json
{
  "type": "matching",
  "question": "Установіть відповідність між реченням (1–4) і виразом, який в ньому є (А–Д).",
  "items": [
    "Листя, зірване вітром, кружляло над нами.",
    "Хлопець ішов, насвистуючи веселу мелодію.",
    "Ми побачили розпалене вогнище.",
    "Стежка, зрадівши волі, вибігла на зруб."
  ],
  "options": [
    "дієприкметниковий зворот",
    "дієприслівниковий зворот",
    "одиничний дієприкметник",
    "порівняльний зворот",
    "вставне слово"
  ],
  "correct": ["А", "Б", "В", "Б"],
  "explanation": "Варіанти Г і Д зайві."
}
```

| Поле | Опис |
|---|---|
| `type` | `"matching"` |
| `question` | Текст завдання |
| `items` | Пункти, які нумеруються автоматично: 1, 2, 3... Без номерів у тексті |
| `options` | Варіанти без літер: перший = А, другий = Б... Можуть бути зайві |
| `correct` | Список літер **у тому ж порядку, що й `items`**. Довжина списку = кількості `items` |
| `explanation` | Необов'язково |

У прикладі `"correct": ["А", "Б", "В", "Б"]` означає: 1–А, 2–Б, 3–В, 4–Б.

Питання за пунктами оцінюється як правильне, лише якщо всі літери вгадані. Після перевірки сайт підсвічує помилкові рядки й показує правильні літери.

### Приклад файлу з двома типами разом

```json
{
  "title": "Мій набір",
  "questions": [
    {
      "type": "single",
      "question": "...",
      "options": ["...", "...", "...", "..."],
      "correct": "А"
    },
    {
      "type": "matching",
      "question": "...",
      "items": ["...", "...", "..."],
      "options": ["...", "...", "...", "..."],
      "correct": ["Б", "А", "Г"]
    }
  ]
}
```

## Готовий запит для нейронки

Скопіюй текст нижче в чат із нейронкою, заміни частину в `[ ]` на свою тему й додай, якщо треба, фото чи текст завдань.

````
Створи файл завдань для тренажера у форматі JSON. Відповідай ТІЛЬКИ валідним JSON без пояснень і без ```.

Тема: [наприклад, дієприкметниковий зворот, 8 питань, рівень НМТ]

Структура:
{
  "title": "Назва набору",
  "questions": [ ... ]
}

Є два типи питань.

1) Звичайне питання з однією правильною відповіддю:
{
  "type": "single",
  "question": "текст питання",
  "options": ["варіант 1", "варіант 2", "варіант 3", "варіант 4"],
  "correct": "В",
  "explanation": "коротке пояснення, чому так"
}

2) Відповідність (пункти 1–4 до варіантів А–Д):
{
  "type": "matching",
  "question": "текст завдання",
  "items": ["пункт 1", "пункт 2", "пункт 3", "пункт 4"],
  "options": ["варіант А", "варіант Б", "варіант В", "варіант Г", "варіант Д"],
  "correct": ["Б", "А", "Г", "В"],
  "explanation": "коротке пояснення"
}

Правила:
- Літери в "correct" тільки УКРАЇНСЬКІ: А Б В Г Д Е. Не латинські.
- У "options" та "items" не пиши літери й номери ("А)", "1."): сайт додає їх сам. Перший елемент "options" = А, другий = Б і так далі.
- У "matching" "correct" — список літер у тому самому порядку, що й "items". Довжина списку = кількості "items".
- У "matching" інколи роби в "options" один зайвий варіант, який не підходить до жодного пункту. Один варіант може підходити до кількох пунктів.
- У "single" від 4 до 5 варіантів, лише один правильний.
- Усі правильні відповіді перевір двічі. Не вигадуй правил, яких не існує.
- Змішуй типи: приблизно 3 питання "single" на 1 питання "matching".
- Мова: українська.
````

Після того як нейронка видасть JSON, збережи його як `exercises/назва.json` і впиши назву в `exercises/index.json`. Завжди перевіряй правильні відповіді сам(а): нейронки помиляються.
